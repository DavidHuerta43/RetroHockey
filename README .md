# Retro Hockey '87

A retro-styled browser hockey game with desktop and touch-oriented
controls.

## Features

-   Virtual on-screen joystick for player movement.
-   Touch buttons for shooting, passing, tackling, and sprinting.
-   Pointer Events support for mouse and touch input.
-   Responsive HUD and game layout.
-   Pause and resume functionality.
-   Match-end states for victory, defeat, and draw.
-   Press `Escape` to pause.
-   Player input is disabled while the game is paused.

## Run locally

1.  Download or clone the project.
2.  Keep the original project files and folders together.
3.  Open the HTML entry point in a modern browser.
4.  Keep any external assets at their expected relative paths.

## External resources

-   **Tailwind CSS** --- loaded remotely.
-   **Press Start 2P** --- typeface loaded remotely.

An internet connection may be required for these resources to load.
